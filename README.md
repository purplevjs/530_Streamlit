# Mortgage Payment Calculator App  
*Built with Streamlit (Python)*

## Project Overview
This project is a simple interactive web app that calculates monthly mortgage payments, total payments over the full loan term, and visualizes the remaining balance over time.

Inspired by the mortgage calculator demonstration from this YouTube tutorial:  
(Only the mortgage calculator portion was used.)

## Features
- Input fields for:
  - Home value (loan amount)
  - Down payment
  - Annual interest rate
  - Loan term (years)
- Outputs:
  - Loan principal after down payment
  - Monthly payment
  - Total amount paid across the loan
- Visualization:
  - Remaining loan balance line chart (amortization progress)



### Prerequisites
- Python 3.x
- pip
- Git

### Installation
#### 1. Clone the repository:
```bash
git clone <your-repo-url>
cd <repo-folder>
```

#### 2. Create a virtual environment (optional but recommended):
```bash
python3 -m venv venv
source venv/bin/activate
```

#### 3. Install dependencies:
```bash
pip install -r requirements.txt
```

#### 4. Running the App:
```bash
streamlit run mortgage_calculator.py
```
